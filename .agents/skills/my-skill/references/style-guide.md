# قارلۇق ئۇسلۇب قوللانمىسى (Style Guide)

## 1. ئۇيغۇر ئەدەبىي تىلى ئۆلچىمى
- جۈملە قۇرۇلمىسى ئۇيغۇر تىلىنىڭ ئەنئەنىۋى گرامماتىكا تەرتىپىگە تولۇق بويسۇنىشى كېرەك: ئىگە + تولۇقلىغۇچى + خەۋەر (SOV).
- چەت ئەل تىللىرىدىكى تەتۈر ياكى مۇرەككەپ مۇناسىۋەتلەر تەرجىمە قىلىنغاندا، ئۇيغۇرچىنىڭ ئەقلىگە ۋە ئاڭلاش رېتىمىغا ماسلاشتۇرۇلىدۇ.
- ئاتالغۇلار بىرلىككە كەلتۈرۈلگەن بولۇپ، پۈتۈن ماقالە ياكى ۋىدىئودا ئوخشاش تەرجىمە قوللىنىلىدۇ.

## 2. ئابزاس ۋە شەكىل تەلىپى
- **يۆنىلىش**: `dir="rtl"` (ئوڭدىن سولغا).
- **ئوڭ-سول تەڭشەش**: `text-align: justify; text-justify: inter-word;` ئارقىلىق سەھىپىنىڭ ئىككى چېتى تۈپتۈز تىزىلىدۇ.
- **باشلىنىش بوشلۇقى**: ئابزاسنىڭ بىرىنچى قۇرى دەل 2 ھەرىپ كەينىدىن باشلىنىدۇ (`text-indent: 2em;`).
- **قۇر ئارىلىقى**: `line-height: 2.0` ياكى `2.2` ئارىلىقىدا بولۇپ، ئەرەب يېزىقىدىكى ھەرىپلەر قىسىلىپ قالمايدۇ.
- **فونت**: `UKIJ Tuz` نۇسخىسى ئالدىنقى ئورۇندا تۇرىدۇ.
