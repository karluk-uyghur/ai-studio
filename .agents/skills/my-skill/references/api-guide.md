# قارلۇق API قوللانمىسى (API Guide)

## 1. تەرجىمە ۋە سىياسىي تەھلىل ئۇچۇر يوللاش API

### POST `/api/translate`
- **ئىقتىدارى**: ھەرقانداق تىلدىكى يازما ياكى ۋىدىئو ترانسكرىپتىنى ئۇيغۇر ئەدەبىي تىلىغا تەرجىمە قىلىدۇ.
- **تەلەپ گەۋدىسى (JSON)**:
  ```json
  {
    "text": "The geopolitical competition between China and Western democracies...",
    "sourceLang": "auto",
    "targetLang": "ug",
    "tone": "literary_political",
    "filterMusic": true
  }
  ```
- **جاۋاب (JSON)**:
  ```json
  {
    "translatedText": "    خىتاي بىلەن غەرب دېموكراتىك ئەللىرى ئوتتۇرىسىدىكى گېئو-سىياسىي رىقابەت كۈندىن-كۈنگە جىددىيلەشمەكتە...",
    "politicalAnalysis": "ماقالىدە خىتاينىڭ خەلقئارالىق سىياسىي بېسىمى ۋە شەرقىي تۈركىستان مەسىلىسىگە تەسىر كۆرسىتىدىغان ئامىللار بايان قىلىنغان.",
    "subtitles": [
      { "id": 1, "start": "00:00:01,000", "end": "00:00:04,500", "text": "خىتاي بىلەن غەرب ئەللىرى ئوتتۇرىسىدىكى كۈرەش" }
    ]
  }
  ```

### POST `/api/analyze-politics`
- **ئىقتىدارى**: خىتاينىڭ ھەربىي-سىياسىي ھەرىكەتلىرى ۋە شەرقىي تۈركىستانغا دائىر چوڭقۇر ئىستراتېگىيىلىك تەھلىل.
