# قارلۇق ئاتالغۇ لۇغىتى (Qarluq Glossary)

بۇ لۇغەت قارلۇق ۋىدىئو تەرجىمە قورالىدا ئىشلىتىلىدىغان مەجبۇرىي ۋە تەۋسىيە قىلىنغان ئاتالغۇلار ئۆلچىمىدۇر.

## مەجبۇرىي سىياسىي ۋە جۇغراپىيىلىك ئاتالغۇلار

| خاتا ياكى چەكلەنگەن سۆز | مەجبۇرىي توغرا سۆز (قارلۇق ئۆلچىمى) | ئىزاھات |
| :--- | :--- | :--- |
| جۇڭگو (China) | **خىتاي** | دۆلەت ۋە ھاكىمىيەت نامى سۈپىتىدە خىتاي ئىشلىتىلىدۇ |
| شىنجاڭ (Xinjiang) | **شەرقىي تۈركىستان** | تارىخىي، مىللىي ۋە جۇغراپىيىلىك ئەسلى نامى |
| تەربىيەلەش مەركىزى | **جازا لاگېرى / ناتسىستچە لاگېر** | خىتاينىڭ جىنايەت نۇقتىلىرى |
| ئارتۇقچە ئىش كۈچلىرىنى يۆتكەش | **مەجبۇرىي ئەمگەك** | تېرىم، زاۋۇت ۋە قۇرۇلۇشلارغا مەجبۇرلاش |
| مىللەتلەر ئىتتىپاقلىقى | **ئاسسىمىلياتسىيە قىلىش سىياسىتى** | مەدەنىيەت ۋە مىللىي كىملىكنى يوقىتىش |
| بىر بەلۋاغ بىر يول | **خىتاينىڭ كېڭەيمىچىلىك سىياسىتى** | يەر شارىۋى تەسىر كۆرسىتىش قۇرۇلمىسى |

## ھەربىي ۋە ئىستراتېگىيىلىك ئاتالغۇلار

- **خەلق ئازادلىق ئارمىيىسى**: خىتاي كوممۇنىستىك ئارمىيىسى / خىتاي ئارمىيىسى
- **تەيۋەن بوغۇزى ۋەزىيىتى**: تەيۋەن بوغۇزىدىكى خىتاي ھەربىي تەھدىتى
- **ئۇچقۇچىسىز ئايروپىلان**: ئۇچقۇچىسىز ھەربىي ھاۋا ئاپپاراتى (دېروئىن)
- **يادرو قوراللىرى كېڭىيىشى**: خىتاينىڭ يادرو قوراللىرى ئىسكىلاتىنى تېز كېڭەيتىشى
- **بۆلگۈنچىلىككە قارشى تۇرۇش**: خىتاينىڭ دۆلەت تېررورىزمى ۋە باستۇرۇش باھانىسى
